# JavaScript Basics: DOM Manipulation & Events

A web programming course project. The site consists of several pages, one per task. It uses only plain HTML, CSS and JavaScript, with no frameworks or libraries.

## Tasks

| Page | Task |
|------|------|
| `task0.html` | Task 0. First Script: `console.log()` and `alert()` |
| `task1.html` | Task 1. Variables & Operators: variables, arithmetic, concatenation |
| `task2.html` | Task 2. Changing Content: change paragraph text on click |
| `task3.html` | Task 3. Changing Styles: change background color and font size |
| `task4.html` | Task 4. Creating & Removing Elements: add and remove `<li>` items |
| `task5.html` | Task 5. Mouse Events: change color on hover (`mouseover` / `mouseout`) |
| `task6.html` | Task 6. Keyboard Events: show typed text in real time (`keyup`) |
| `task7.html` | Task 7. Calculator: addition, subtraction, multiplication, division |
| `task8.html` | Task 8. To-Do App: task list with delete and "done" toggle |

## Project structure

```
js-dom-tasks/
├── index.html      # home page
├── style.css       # shared styles for all pages
├── task0.html ... task8.html
├── task0.js ... task8.js

```

## Running locally

1. Download or clone the repository.
2. Open `index.html` in a browser (double-click).
3. For Task 0 and Task 1, open the developer console (F12 -> Console).

No server or dependencies are required.

## Publishing on GitHub Pages

1. Create a new public repository on GitHub (for example `js-dom-tasks`).
2. Upload all project files to the root of the repository.
3. Open **Settings -> Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose the `main` branch and the `/ (root)` folder, then click **Save**.
5. After 1-2 minutes the site will be available at:
   `https://github.com/93rdmogila/Assignment4Web`
